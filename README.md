# Trekhive 🏔️

> **🚧 Trekhive is currently under development.**  
> Features are being added progressively, so some functionality may be incomplete or unavailable.

Trekhive is a modern full-stack web application designed for exploring, reviewing, and sharing outdoor trails and campsite locations.

---

## 🛠️ Current Tech Stack

* **Backend:** Node.js (ES Modules), Express.js
* **Database:** MongoDB, Mongoose ODM
* **Templating Engine:** EJS (Embedded JavaScript)
* **Styling:** Tailwind CSS v4
